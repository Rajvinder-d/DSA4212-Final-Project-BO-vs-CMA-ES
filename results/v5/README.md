# V5 boundary-handler results

Curated exports of the executed v5 comparison, copied byte-for-byte from the
verifier output so the SHA-256 hashes in `analysis_validation.json` remain valid.
Generated by [`scripts/analyse_v5.py`](../../scripts/analyse_v5.py) from the ignored collection
`artifacts/boundary-v5-windows-jax/` (analysis snapshot `20261111T181415-f0dfa925`).
The raw collection is **not** committed: `/artifacts/` is gitignored, and the
per-run traces remain the underlying evidence for independent verification and
regeneration of these summaries.

These exports are retained for report preparation. The V5 implementation and
tests accompany this export. See the
[report interpretations](../../docs/REPORT_INTERPRETATIONS.md) for the scientific
argument and its limits.

The tables were written on Windows and use CRLF; `.gitattributes` marks
`results/v5/*.csv` as `-text` so a clone receives the same bytes the hashes were
computed over.

## Tables

| File | Rows | Content |

| `run_status.csv` | 100 | Per-run completion status |
| `attempts.csv` | 101 | Resource accounting per attempt, including the one unclosed 262-call partial attempt |
| `analysis_validation.json` | — | Verifier counts, output hashes and collection/analysis hashes |
| `execution_validation.json` | — | Environment, provenance, test/parity results and run accounting for the whole execution |

## Scope

These are descriptive results from a prospective design fixed before execution:
one CALCE SP20-2 DST cell, the five-parameter two-RC model, the ball-constrained
battery objective, initial-design seeds 30–39, full CMA with resampling versus
radial projection, BO and random comparators, checkpoints at 100 and 300 counted
calls. Intervals resample the 10 design groups, not runs.

The tables support the handler contrast and the BO–CMA gap by handler and budget.
They do **not** isolate "surface access" from the changed accepted distribution
and subsequent adaptation, do not establish an equal-time ranking, and do not
generalise beyond this cell, objective, domain and settings. The
[frozen protocol](../../docs/FOLLOWUP_PROTOCOL_V5.md)
records the design; [execution_validation.json](execution_validation.json)
records the execution and environment.
